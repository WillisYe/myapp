CSS 2026 新特性演示

1. 自定义CSS函数

CSS 2026引入的@function语法，允许开发者定义可复用的计算逻辑，支持参数传递、条件判断和数学运算。

示例代码：

@function calcPadding($base, $factor) { @return calc($base * $factor); } .container { padding: calcPadding(1rem, 1.5); @media (max-width: 768px) { padding: calcPadding(1rem, 1); } }

演示效果：

这个容器使用了自定义函数计算内边距，在不同屏幕尺寸下会自动调整。

2. border-shape属性

通过shape()函数定义任意几何形状，支持路径定义、贝塞尔曲线和复杂多边形。

示例代码：

.shape { border-shape: shape(circle, 50%); border-color: red; transition: border-shape 0.3s; } .shape:hover { border-shape: shape(rectangle, 100px 100px); }

演示效果：

鼠标悬停查看边框形状变化

3. attr()函数进化

attr()函数现在支持类型自动识别，可直接读取HTML属性值，自动识别数字、颜色、长度等类型。

示例代码：

.progress { height: 20px; background: linear-gradient(to right, attr(data-color, color) 0%, transparent 100%); width: attr(data-width, number)%; }

4. 滚动状态查询

通过@container规则查询滚动状态，可实时检测元素的滚动状态，实现动态样式调整。

示例代码：

@container scroll-state(stuck: top) { .nav { box-shadow: 0 4px 6px -1px rgba(0,0,0,0.1); } } @container scroll-state(rolling) { .scroll-indicator { background: rgba(0,0,0,0.3); } }

5. 媒体元素伪类

新增的媒体元素伪类支持直接绑定视频播放/暂停/缓冲等状态。

示例代码：

.video { border: 2px solid transparent; transition: border 0.3s; } .video:playing { border-color: #2196F3; } .video:paused { border-color: #9E9E9E; }

演示效果：

播放视频时，边框会变为蓝色；暂停时，边框会变为灰色。

6. 容器查询与:has()选择器

@container规则实现组件级自适应，:has()选择器实现父元素基于子元素状态的样式化。

示例代码：

@container (max-width: 600px) { .grid { grid-template-columns: 1fr; } } @container (min-width: 768px) { .grid { grid-template-columns: repeat(3, 1fr); } } .parent:has(.child:playing) { background: #F5F5F5; }
