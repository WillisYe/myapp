🎯 Container Queries 演示

调整浏览器窗口或父容器宽度，观察卡片布局变化：

响应式卡片

当容器宽度 ≥ 400px 时，采用双列布局；小于 400px 时，采用单列垂直布局。

这就是容器查询的强大之处！

@layer components { .card-container { container-type: inline-size; container-name: card-container; } .responsive-card { /* 默认样式 */ @container card-container (min-width: 400px) { display: grid; grid-template-columns: 1fr 2fr; } @container card-container (max-width: 399px) { text-align: center; } } }

⚖️ @layer 层叠层优先级演示

通过 @layer 精确控制 CSS 优先级，避免 specificity 战争：

优先级测试

这个元素应用了 @layer utilities 的样式（最高优先级）

层级顺序：reset → base → components → utilities

/* 定义层顺序 */ @layer reset, base, components, utilities; /* 低优先级层 */ @layer base { .priority-test { background: oklch(50% 0.1 240); } } /* 中优先级层 */ @layer components { .priority-test { background: oklch(85% 0.1 240); } } /* 高优先级层 */ @layer utilities { .priority-test { background: oklch(85% 0.1 150) !important; color: oklch(30% 0.08 150); } }
